# 🐍 Python Mini Projects

Welcome to my **Python Mini Projects** repository!

This repository contains beginner-friendly Python projects that I built while learning Python programming. These projects helped me practice core Python concepts and improve my problem-solving skills.

## 📚 Projects Included

### 1. 🧮 Calculator
A simple calculator that performs:
- Addition
- Subtraction
- Multiplication
- Division

### 2. 🎯 Number Guessing Game
A game where the user guesses a randomly generated number.

### 3. 🔐 Password Generator
Generates strong random passwords using letters, numbers, and symbols.

### 4. ✊ Rock Paper Scissors
Play Rock, Paper, Scissors against the computer.

### 5. 📝 To-Do List
A simple console-based application to:
- Add tasks
- View tasks
- Remove tasks

### 6. 📒 Contact Book
Manage contacts by:
- Adding contacts
- Viewing contacts
- Searching contacts
- Deleting contacts

### 7. ❓ Quiz Game
A multiple-choice quiz that keeps track of the user's score.

### 8. 🏧 ATM Simulator
A basic ATM system with:
- Balance inquiry
- Deposit
- Withdraw
- Exit

### 9. 🎓 Student Management System
Manage student records by:
- Adding students
- Viewing students
- Searching students
- Deleting students

### 10. 📂 File Organizer
Automatically organizes files into folders based on their file extensions.
